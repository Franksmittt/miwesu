# AI Image Prompts – Blue Wildebeest, Greater Kudu, Impala

**Use for:** Limpopo bushveld / Makoppa-style game reserve. **Flat land only – no mountains.** Beautiful natural wildlife only – no hunters, no weapons, no blood, no mutilation.

---

## Limpopo vegetation (use in every prompt)

| Element | Description |
|--------|-------------|
| **Terrain** | Flat to gently undulating. No mountains, cliffs, or dramatic peaks. |
| **Soil** | Red to reddish-brown (iron-rich Hutton-type). Fine, can show tracks. |
| **Grass** | Short to medium sweetveld; dry season: pale straw/yellow; wet: green. |
| **Trees** | Mopane (butterfly leaves, copper in dry season), Sicklebush, Acacia (thorny, flat-topped), Leadwood, Grewia. Sparse to moderate, not dense forest. |
| **Forbidden** | Mountains, snow, rainforest, dunes, people, vehicles, fences, hunting, blood, dead/wounded animals. |
