================================================================================
1. PROJECT OVERVIEW
================================================================================

MIWESU GAME FARM is a luxury private residence and game farm website in the
Makoppa district, Thabazimbi, Limpopo, South Africa. It showcases exclusive
accommodation (The Homestead, Stone Villa), ethical hunting and conservation
harvest, Miwesu Premium Firewood (Engineered Heat), and full booking, tools,
and trust architecture for international and local (SA) audiences.

The site is built with Next.js 15 App Router, React 19, TypeScript, Tailwind,
Prisma (PostgreSQL), and Stripe. Design follows "Hardware Noir" and "Liquid
Glass" with Bento Grids for technical data, gold/onyx/marble palette, Cinzel
+ Montserrat, and sensory UX (ambient audio toggle, haptic feedback on primary
actions).

9. API ROUTES
================================================================================

GET  /api/availability     — Returns available options (units) for date range; uses Prisma if DATABASE_URL set else mock.
POST /api/checkout         — Creates Stripe Checkout session; returns url or demo message.
POST /api/contact          — Sends contact form via Resend; 503 if no RESEND_API_KEY.
POST /api/saps520/pdf      — Body: applicant, travel, firearms (max 4). Returns PDF (pdf-lib); Buffer.from(pdfBytes).
GET  /api/telemetry        — Returns { conservation, kiln } simulated data (hectares, hours, ZAR, moisture, temp, batch).
POST /api/webhooks/stripe  — Stripe webhook; updates booking status.
GET  /api/admin/bookings   — Returns bookings list; protected by admin secret.
POST /api/wood-order       — Wood order submission (email/CORS config).
