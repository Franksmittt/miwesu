## Shot placement (all species)

Use the same style for every shot placement diagram:

- **Format:** One image per species, 4:5 vertical.
- **Content:** Animal in broadside view with a single target marking vitals (one-third up, just behind front leg).
- **Style:** Clean technical illustration; no text on image; uniform across species.
- **Reference:** `docs/SHOT_PLACEMENT_IMAGE_PROMPTS.json` has per-species prompts and suggested filenames.

Red Hartebeest already uses `redhardt_Shotplacement.png`; you can replace it with a diagram in the same style for consistency.
