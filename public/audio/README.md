# Ambient audio

Add a file named **bushveld.mp3** here for the optional bushveld soundscape (used by the ambient-audio toggle in the main navigation).

- Format: MP3 (or any format supported by the browser).
- Suggested: low-volume loop (e.g. bushveld ambience, distant birds, subtle fire crackle). The app plays it at 15% volume when the user enables it.

If this file is missing, the toggle still appears; play will simply not start (no errors).
