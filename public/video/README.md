# Optional hero video

Place a **muted, looping** MP4 here as `hero-cinematic.mp4` for the home hero background.

- **Codec:** H.264 / AAC (MP4) for broad browser support  
- **Aspect:** Wide (16:9 or broader); object-fit covers the viewport  
- **Content:** Bushveld, iron-rich earth, texture — avoid misleading “live feed” claims  

If the file is missing, the hero falls back to the static panoramic image automatically.
